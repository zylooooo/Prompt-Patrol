# Dataset Card: Mohler ASAG (as used in Prompt Patrol)

This documents the Mohler corpus **after**  ingestion and
cleaning.

## Source & provenance

- **Upstream repo:** `nkazi/MohlerASAG`, HuggingFace dataset
- **Pinned revision:** `dac06732b42d01a5169f543f6d272f1476cced3e` (see
  `app/config.py`'s `DATASET_REVISION` - pinned so this corpus can never
  silently change if the upstream repo is updated)
- **Config used:** `raw` (the authors' unaltered original text, not their own
  pre-cleaned `cleaned`/`parsed` variants - we run our own cleaning pass
  instead, documented below)
- **License:** CC-BY-4.0
- **Original source:** Mohler & Mihalcea (2009, extended 2011), collected
  from an introductory data structures course at the University of North
  Texas

## Composition

- 87 questions across 12 assignments/exams (`E01`-`E12`), covering both
  `open_ended` (2,206 rows) and `close_ended` (141 rows) question types
- Schema: `id, question, instructor_answer, student_answer, split`
- `id` format: `EXX.QXX.AXX` (exercise, question, answer)

## Cleaning performed (PP-75/PP-76)

Starting from 2,442 raw rows:

| Issue | Found | Action |
|---|---|---|
| Duplicate `id`s | 0 | none needed |
| Duplicate `(question, student_answer)` pairs | 142 rows (47 distinct groups) | 95 dropped, keeping the lowest `id` per group |
| Encoding artifacts (unescaped HTML entities, e.g. `&lt;`/`&gt;`) | 5 rows | fixed in place via `ftfy` |
| Blank/missing text | 0 | none needed |

**Result: 2,442 raw rows -> 2,347 cleaned rows.**

The 142 duplicate-answer rows were mostly independent students converging on
the same short correct answer to terse factual questions (e.g. "push" for
"what's the stack operation for enqueue") - not data errors. Full per-row
detail (exact IDs fixed/dropped and why) is in `data/cleaning_log.json`,
regenerated by `app/cleaning.py`.

## Key characteristics (full analysis: `notebooks/eda.ipynb`)

- **Answer length:** median 16 words, mean ~19, range 1-173 - confirms this
  is genuinely short-answer data
- Tracked specifically as a baseline: if future AI-generated answers come out
  systematically longer or shorter than this, a detector could learn to key
  off length as a shortcut instead of real authorship signal
- Row counts skew toward later exercises (E11: 296 rows, E12: 269 rows) vs.
  earlier ones (E05: 110 rows) - exercises are not evenly sized

## Known limitations

- Single course, single domain (introductory data structures), one
  institution

## Splits (PP-115/PP-116)

Question-level train/val/test split (70/15/15), keeping every answer to a
given question in the same partition - see `app/splitting.py`. Current
version `2cc2d581`:

| Partition | Rows | Questions |
|---|---|---|
| train | 1,644 | 59 |
| val | 353 | 13 |
| test | 350 | 13 |

0 leakage confirmed across all 85 questions (`app/leakage_check.py`). Full
manifest: `data/splits/mohler_splits_2cc2d581_manifest.json`.
