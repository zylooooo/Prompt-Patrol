# Dataset Card: SPRAG (as used in Prompt Patrol)

This documents the SPRAG corpus after this project's own ingestion and
cleaning pass - not the original dataset as published. For the original
source, see [sridevibonthu/SPRAG](https://github.com/sridevibonthu/SPRAG) on
GitHub.

## Source & provenance

- **Upstream repo:** `sridevibonthu/SPRAG` on GitHub (plain CSVs, not a
  HuggingFace `datasets` repo)
- **Pinned revision:** commit `18417d626069` (see `app/config.py`'s
  `SPRAG_REVISION` - pinned the same way as Mohler's HF revision, just via a
  GitHub commit SHA instead of a HF one)
- **Files used:** `Question_data.csv` (question text/type/reference answer)
  joined with `PyResponses.csv` (student answers/scores) on `QuestionID`.
  `MLResponses.csv` (a separate Machine Learning course) is out of scope -
  not a software-engineering topic.
- **License:** no formal license file on the repo, but the author's own
  README explicitly invites download and provides a citation format -
  sufficient for academic/research use, though not a permissive open-source
  license like Mohler's CC-BY-4.0.
- **Original source:** Bonthu, S. et al., "SPRAG: building and benchmarking
  a Short Programming-Related Answer Grading dataset" (2024), collected from
  a real Python programming course.

## Composition

- 68 unique questions with recorded answers (of 148 total in
  `Question_data.csv` - not all questions received responses)
- Schema: `id, QuestionID, StudentAnswer, QuestionText, QuestionType,
  Reference Answer`
- `id` is a synthetic identifier (`{QuestionID}.A{n}`) - the source has no
  natural per-row id, unlike Mohler's `id` column

## Cleaning performed

Starting from 2,929 raw rows:

| Issue | Found | Action |
|---|---|---|
| Encoding artifacts | 3 rows | fixed in place via `ftfy` |
| Missing/blank answers | 5 rows | dropped |
| Duplicate `(QuestionID, StudentAnswer)` pairs | 123 rows | dropped, keeping the first `id` per group |
| Code-eliciting questions (verified by text pattern) | 279 rows | dropped entirely |

**Result: 2,929 raw rows -> 2,522 cleaned rows.**

Full per-row detail (exact IDs fixed/dropped and why) is in
`data/sprag_cleaning_log.json`, regenerated by `app/sprag/cleaning.py`.

## Intended use

The human-authored half of this project's AI-vs-human short-answer detection
corpus, alongside Mohler - not a general-purpose dataset, and not intended
for automated grading research (the original purpose SPRAG was built for).
