# Dataset Card: EngSAF (as used in Prompt Patrol)

This documents the EngSAF corpus after this project's own ingestion,
scope-filtering, and cleaning pass - not the original dataset as published.
For the original source, see
[IsmaelMousa/engsaf](https://huggingface.co/datasets/IsmaelMousa/engsaf) on
HuggingFace.

## Source & provenance

- **Upstream repo:** `IsmaelMousa/engsaf` on HuggingFace
- **Pinned revision:** commit `0a2b17a9793bc5dd1a7bde26f87bc58a2d31732f` (see
  `app/config.py`'s `ENGSAF_REVISION`)
- **Files used:** the dataset's native `train`/`validation`/`test` splits,
  concatenated into one table with a `split` column retained for reference
  only - this project's own `question-level-splits` (PP-115) will re-split
  from scratch once the Mohler+SPRAG+EngSAF combine step exists, so EngSAF's
  original split is not used downstream.
- **License:** see the upstream repo's own license terms.
- **Original source:** derived from real engineering exam short-answer
  responses, published as an automatic short-answer-grading (ASAG) benchmark.

## Composition & scope

Unlike Mohler and SPRAG, EngSAF is **not** a software-engineering-specific
corpus - it spans many engineering disciplines (hydrology, materials
science, image processing, statistics, manufacturing, finance, environmental
engineering, and more), and has no topic/subject column to filter on.

Every one of the 118 unique questions in the raw corpus was read directly and
categorized by topic (mirroring how SPRAG's code-eliciting questions were
verified by text rather than trusting a label). Everything
else (hydrology, materials science, image processing, ML/pattern
recognition, manufacturing, finance, management, etc.) is out of scope and
dropped entirely.

- Raw: 5,579 rows, 118 unique questions
- Schema: `id, question_id, question, student_answer, reference_answer,
  mark_scheme, score, rationale, split`
- `id` and `question_id` are synthetic identifiers - the source has no
  natural per-row or per-question id.

## Cleaning performed

Starting from 5,579 raw rows:

| Issue | Found | Action |
|---|---|---|
| Encoding artifacts (all one question's `&gt;` entity) | 53 rows | fixed in place via `ftfy` |
| Missing/blank answers | 1 row | dropped |
| Duplicate `(question, student_answer)` pairs | 15 rows | dropped, keeping the first `id` per group |
| Out-of-scope questions (100 of 118, non OS/software-engineering topics) | 3,109 rows | dropped entirely |

Grader-output columns `score`, `rationale`, and `mark_scheme` were dropped -
`score`/`rationale` are human-grader outputs that AI-generated answers will
never have (same reasoning as Mohler/SPRAG's dropped score columns);
`mark_scheme` is the same fixed 0/1/2 rubric text on every row, not per-answer
content.

**Result: 5,579 raw rows -> 2,454 cleaned rows.**

Full per-row detail (exact IDs fixed/dropped and why) is in
`data/engsaf_cleaning_log.json`, regenerated by `app/engsaf/cleaning.py`.
